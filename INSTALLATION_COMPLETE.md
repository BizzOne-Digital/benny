## 🚀 Quick Start (5 Minutes)

### 1. Verify Installation

```bash
npm run verify
```

This checks all files are in place.

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment

```bash
cp .env.example .env
```

Edit `.env` with your MongoDB URI and credentials.

### 4. Seed Database

```bash
npm run seed
```

Creates admin user and sample content.

### 5. Start Development

```bash
npm run dev
```

Visit:
- Public: http://localhost:3000
- Admin: http://localhost:3000/admin

### Common Issues

**MongoDB Connection Error:**
- Check MONGODB_URI in .env
- Verify network access in Atlas
- Confirm credentials

**Images Not Uploading:**
- Ensure public/uploads exists
- Check folder permissions
- For production, configure Vercel Blob

**Build Errors:**
- Run `npm run type-check`
- Run `npm run lint`
- Check error messages

### File Locations

- **Configuration:** Root directory (*.config.*)
- **Public Pages:** src/app/(public)/
- **Admin Portal:** src/app/admin/
- **Components:** src/components/
- **Database:** src/models/
- **Utilities:** src/lib/
- **Styles:** src/app/globals.css
